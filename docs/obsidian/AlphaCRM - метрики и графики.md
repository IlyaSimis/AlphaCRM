# AlphaCRM - метрики и графики

> [!summary] Принцип
> Не «дашборды ради дашбордов», а метрики под решения ролей. На home — 3–5 цифр; тренды — в аналитике менеджера. Клинический текст в графики не попадает.

Родительское ТЗ: [[AlphaCRM - переделка в сервисы]]  
Карта заметок: [[AlphaCRM]]

## Обязательный минимум

Связано с сервисами: [[AlphaCRM - сервис Расписание]], [[AlphaCRM - сервис Финансы]], [[AlphaCRM - сервис Склад]].

### Загрузка и запись
- Запись / явка / отмена / no-show за день · неделю · месяц
- Загрузка кабинетов и врачей (% занятых слотов)
- Среднее время до ближайшего свободного слота по специальности
- Лист ожидания: сколько человек, сколько конвертировалось в запись

### Деньги (без клинического текста)
- Выручка и оплаты vs выставленные счета («висящие» долги)
- Средний чек; структура по услугам / врачам / дням недели
- Доля свободного прайса vs фиксированного → см. [[AlphaCRM - переделка в сервисы#3. Свободный прайс|свободный прайс]]
- Возвраты / отмены оплаченных (когда появятся)

### Воронка пациента
- Новые пациенты vs повторные
- Конверсия: первый контакт → запись → визит → оплата
- Доля пациентов без следующего визита после завершённого приёма (ретеншн)

## По ролям на приветственной странице

Первая страница после входа — персональный дашборд (см. [[AlphaCRM - переделка в сервисы#1.4 Дашборды / расписание|дашборды / расписание]]).

| Роль | Что видеть сразу |
|---|---|
| [[Роль Администратор\|Администратор]] | Записи сегодня/завтра, касса за день, долги, «дыры» в расписании, задачи регистратуры |
| [[Роль Врач\|Врач]] | Приёмы за месяц, сегодняшняя сетка, no-show по своим слотам, незакрытые приёмы/документы |
| [[Роль Менеджер\|Менеджер]] | Выручка, загрузка, топ услуг/врачей, тренды 4–12 недель, отмены |
| [[Роль Медперсонал\|Мед. персонал]] | Склад: критичные остатки, списания за период; расписание смен |
| [[Роль Владелец\|Владелец]] | Сводка P&L-лайт: выручка, фонд занятости, отмены, остатки/списания; без чужих зарплат у админа |
| [[Роль Старший администратор\|Старший администратор]] | Как администратор + доступ к созданным отчётам |
| [[Роль Техподдержка\|Техподдержка]] | Операционные статусы интеграций (касса, Честный знак), **без** пациентских/клинических метрик |

## Склад

Когда появится [[AlphaCRM - сервис Склад]]:

- Остатки по категориям + ниже min stock
- Оборачиваемость / дни запаса
- Списания vs приходы; потери / просрочка
- Честный знак (позже): % промаркированных движений, ошибки обмена — операционная метрика, не «красота»

---

## Диск и процессы

[[AlphaCRM - сервис Диск]] слабо даёт KPI для клиники. Важнее **операционные очереди**, не pie chart:

- незакрытые приёмы
- неподписанные документы
- счета без оплаты

---

## Чего не тащить в v1

- Сложный BI «как Power BI»
- Клинические outcome-метрики в общих графиках (этика + изоляция данных)
- Зарплатные дашборды у администратора (запрет по RBAC)
- Десятки KPI на одном экране

---

## Раскладка экранов

1. **Home сотрудника** — 3–5 персональных KPI + быстрые действия  
2. **Аналитика менеджера** — тренды: выручка, визиты, no-show, загрузка  
3. **Касса** — день/период, долги, структура оплат → [[AlphaCRM - сервис Финансы]]  
4. **Склад** — остатки и алерты → [[AlphaCRM - сервис Склад]]  

---

## Восемь метрик «на стену»

Минимальный набор для владельца/менеджера:

1. Явка  
2. No-show  
3. Загрузка врачей  
4. Выручка  
5. Средний чек  
6. Долги по счетам  
7. Новые vs повторные  
8. Критичные остатки склада  

Остальное — drill-down по роли, не главный экран.
