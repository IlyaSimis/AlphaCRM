# Прототип системы психиатрической клиники

Интерактивный frontend-прототип внутренней системы амбулаторной клиники. Реализованы расписание и запись, поиск и административная карточка пациента, врачебный приём, подписание и блокировка медицинского документа, а также разграничение административного и клинического доступа.

Все данные синтетические и хранятся только в состоянии браузера. Backend и реальные медицинские интеграции отсутствуют.

## Запуск

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 43127
```

## Проверки

```bash
npm run lint
npm test
npm run build
```

Стек: React 19, TypeScript, Vite и MUI.
